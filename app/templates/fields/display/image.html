{# A stored image, served through this application's file route. The `?store=` is the field's own store, so an image kept somewhere other than the default -- another system's bucket, attached read-only -- resolves to the store that actually holds it rather than 404ing against the default one. Larger on a detail page than in a table cell: a 32px thumbnail is an identifier in a list and useless as a photograph. #} {%- set info = value|file_info -%} {%- set store = field.options.get('store', '') -%} {% if info.key %} {%- set src = '/files/' ~ info.key ~ ('?store=' ~ store if store else '') -%} {% else %}{{ ''|blank }}{% endif %}
