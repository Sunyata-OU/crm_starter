{# Calls Keycloak's own impersonation endpoint as the operator. This has to be a `fetch()` with an `Authorization: Bearer` header, not a form POST: Keycloak scopes its SSO cookies to `Path=/realms/{realm}/`, so a request to `/admin/realms/...` never carries them regardless of SameSite -- a plain form submission would reach Keycloak with no credential at all. Keycloak's admin API is Bearer-authenticated like every other endpoint under `/admin/`, and its CORS config allows this origin to call it with `credentials: "include"`, which is what lets the browser store the `Set-Cookie` the response carries for the *impersonated* user.
